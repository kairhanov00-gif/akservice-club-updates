# АКсервис Клуб — обновления

Отсюда программа «АКсервис Клуб» сама скачивает новые версии.

- `latest.json` — какая версия последняя (номер, файл, контрольная сумма, что нового).
- `latest.json.sig` — подпись АКсервис. Программа ставит обновление только с верной подписью.
- `updates/app_<версия>.zip` — скомпилированная программа, без исходников.

Без лицензии программа работает только в демо-режиме 14 дней.
